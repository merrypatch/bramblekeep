# Getting started

Welcome. This documentation ships inside the binary you are running, so it always
describes **this** version — nothing to fetch, nothing to keep in sync.

Everything here is made of two things: **pages** and **blocks**. A page holds
blocks; a block is a paragraph, a heading, a list item, an image, a table, an
embedded database. That is the whole model, and every feature is a new way of
looking at it.

## Create your first page

In the sidebar, click **Add** and choose *Page*. You get an empty page with a
title, and two optional touches above it: an **icon** (emoji or a picture) and a
**cover** image, which you can pick from Unsplash without leaving the app.

Type a title, press Enter, and start writing.

## Write with blocks

Each paragraph is a block. Press Enter to start a new one, and use the block menu
to change what it is.

Type **`/`** anywhere on an empty line to open the insert menu:

- headings, lists, checklists, quotes, code blocks, tables
- images, files and videos (upload, or paste a link — remote images are mirrored
  locally, so your pages keep working if the source disappears)
- a **sub-page**, created inside the current one
- a **link to an existing page**
- a **database**, either as its own page or embedded right here

Type **`@`** to mention another page or a database row: you get a live chip that
follows the target's title and turns grey if it becomes unavailable.

## Change a block's type

Hover a block: a **⋮⋮** handle appears on its left. Click it, then
**Turn into** — a paragraph becomes a heading, a checklist item, a quote or a
code block, without losing its text or its position.

The same menu sets a **colour**, for the text or for the background of the block.

## Organise the sidebar

The page tree is yours to arrange:

- **drag a page** to reorder it among its siblings, drop it *onto* another page to
  make it a sub-page, or drop it on the dashed zone at the bottom to pull it back
  out to the root
- on a phone, or from the keyboard, use **Move to…** in the page's menu
- a **star** pins a page to Favourites — that is personal, nobody else sees it
- **Recents** lists what you opened last, so you rarely have to hunt

The search field at the top of the sidebar looks inside the content of your
pages, not just their titles.

## Nothing is lost

Deleting a page moves it to the **Trash**, where it stays for 30 days before it
is really destroyed; you can restore it from there. Every page also keeps a
**history**: open the page menu and browse what changed.

Your content is synchronised as you type, and survives a restart of the server —
that is a hard requirement of the project, not a hopeful claim.
